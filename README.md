# GeorgieOS 🖥️

A personal portfolio built to look and feel like a desktop operating system. Instead of a typical portfolio page, you get a fully interactive desktop experience — open apps, change wallpapers, play music, and explore my work, all from a fake OS right in your browser.

## What's inside

The desktop comes with a bunch of apps you can open and interact with:

- **About Me** — a quick intro to who I am
- **Projects** — a look at the things I've built
- **Resume** — my CV, available to view and download
- **Contact** — ways to get in touch
- **Music Player** — a built-in player with a few tracks
- **Games** — yes, there are games
- **Wallpapers** — change the desktop background
- **My Computer** — just for the vibe

---

## Built with

- React + TypeScript
- Vite
- CSS (custom, no UI libraries)

---

## Running it locally

```bash
git clone https://github.com/GiorgiMumladze/GeorgieOS-source
cd GeorgieOS-source
npm install
npm run dev
```
